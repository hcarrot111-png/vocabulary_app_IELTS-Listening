# 小程序端在线预览与微信开发源码包

本包同时用于在线展示和微信小程序继续开发。

## 上传到网站查看效果

请将压缩包整体上传到支持静态网站部署的平台。根目录已经放置 `index.html`，平台生成的访问链接会直接展示手机小程序端交互 Demo。

如果平台要求手动选择“发布目录”或“站点根目录”，请选择压缩包根目录，不要选择 `miniprogram`。

## 交给同事继续开发

`miniprogram` 文件夹是标准原生微信小程序工程。同事使用微信开发者工具时，选择“导入项目”，项目目录选择 `miniprogram`。

## 两部分的区别

- `index.html`：用于浏览器在线预览产品效果。
- `miniprogram/`：WXML、WXSS、JavaScript 和项目配置组成的真实微信小程序源码。

网页预览和微信小程序源码目前使用同一版产品需求，但属于两套运行环境。后续改动应同步维护两端。

## 2026-09-18 同步更新

- 词表更新为网页端 v2 的 C11–21 示例数据。
- 考点词同替练习根据同替数量自动生成 3 个或 5 个居中选项。
- 话题词词义速记固定为 3 个选项。
- 答案词显示词汇难度；话题词显示所属话题和词汇难度。
- 复习详情同步展示难度、话题及中英文高亮。
- 答案词拼写首次错误后，错误字母可删除并重新输入。
- 首次错误阶段提供“再次确认”和“查看答案”，暂不提前展示答案与例句。
- 再次确认或查看答案后才展示正确答案、例句及中文翻译。
- 答案页会根据“显示释义”设置去重，避免重复显示相同释义。
- 话题词初始答题页同时保留“查看解析”和“确认答案”两个并列入口；确认答案后只显示作答结果，不自动展开解析。
- 点击“查看解析”直接展示单词、音标、释义、选项判定、例句和例句中文译文；点击“再听一遍”会清空本词作答状态并回到初始界面。
- 复习详情中，答案词显示单词难度；话题词同时显示单词难度和单词话题。
