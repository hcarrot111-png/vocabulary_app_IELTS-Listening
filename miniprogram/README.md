# 听力词汇练习微信小程序源码

这是可被微信开发者工具直接导入的原生微信小程序工程，不是 HTML 演示文件。

## 导入方式

1. 解压 ZIP。
2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择解压后的本文件夹。
4. 首次预览可使用测试号；正式开发时，将 `project.config.json` 中的 `appid` 改为项目真实 AppID。

## 页面结构

- `pages/book`：考点词、答案词、话题词入口及模式弹窗。
- `pages/groups`：18组词组选择及模式弹窗。
- `pages/practice`：刷词、同替多选、答案词拼写、话题词词义选择；支持普通词书和混合复习队列。
- `pages/review`：错词列表、词书/时间多选筛选、复习设置、混合复习、分类详情抽屉。
- `pages/stats`：学习统计、可点击的近7天趋势和词汇掌握度。
- `utils/data.js`：演示词汇数据。
- `services/review.js`：错词和复习队列本地存储服务。
- `services/audio.js`：真实音频资源接入层。

## 已实现的产品逻辑

- 答错自动加入复习。
- 按用户选择的词书类型、时间和每组数量生成复习队列。
- 全选时混合复习考点词、答案词、话题词。
- 从复习入口进入练习后，返回按钮回到复习页。
- 从普通词书进入练习后，返回对应词组页。
- 考点词、答案词、话题词详情展示不同字段和高亮内容。
- 模式选择采用毛玻璃弹窗。
- 答案词拼写首次错误后允许修改错误字母，并提供“再次确认”和“查看答案”。
- 再次确认或查看答案前不展示正确答案、例句及中文翻译。
- 答案页根据“显示释义”设置去重：练习中已显示释义时答案页不再重复；关闭时答案页仅显示一次。

## 继续开发前需要接入

1. **AppID**：将测试 AppID 替换为正式小程序 AppID。
2. **音频**：在 `app.js` 配置 `audioBaseUrl`，或改写 `services/audio.js` 对接项目的音频接口。当前无真实音频 URL 时会显示待接入提示。
3. **后端数据**：用接口替换 `utils/data.js` 的演示数据；可保留页面所使用的字段结构。
4. **用户同步**：当前错词和复习队列使用 `wx.setStorageSync`；登录和跨设备同步需要接入用户服务。
5. **文件导出**：小程序端 PDF/CSV/Word 需要服务端生成文件后，使用 `wx.downloadFile` 和 `wx.openDocument` 打开。页面中已保留导出入口。
6. **统计接口**：当前统计页为演示数据，需替换为真实学习记录接口。

## 数据字段约定

每个词条至少包含：`id`、`type`、`book`、`word`、`phon`、`pos`、`meaning`。考点词增加 `synonyms`、`question`、`corresponding`、`translation`；答案词和话题词增加 `example`、`translation`。
